  2. Codies

A collection of small science-based programs

with high visual impact or interaction

Web-interactive programs:

  • pyodide/: physics simulations with the pyodide Python-JavaScript interface:
    • Aztec Diamonds tiling: the Arctic Circle theorem
    • Deterministic chaos in the Logistic map
    • the Lorenz attractor (based on gitlab.com/uduh/physics-simulations)
    • Deterministic chaos in the double pendulum system (based on gitlab.com/uduh/physics-simulations)
  • js/: codes written in JavaScript and HTML:
    • vis-network An example of network visualization with the vis-network.min.js library

Not for web (local programs):

  • py/: Python scripts:
    • mab: play against the Macchina a Bicchieri (MAB), a simple example of machine learning (originally with glasses, pen and paper)
    • aztec_diamond: generate and visualize Aztec diamond tilings
    • bifurcation, biliard, logistic_map, lorenz, n_body, pendulum are copied from gitlab.com/uduh/physics-simulations
    • graphlib: a naive attempt to make a library for generating and plotting graphs
    • twitching: simulations of twitching bacteria, from my 2020 Bachelor's thesis
  • ipynb/: Jupyter notebooks:
    • orbits, julia, eigenman, bubbly reproduce artworks by profconradi.com
    • the other notebooks are miscellaneous
  • c/: C programs:
    • mandelbrot: generate the Mandelbrot fractal set
